# 💭 Ideas Futuras

Ideas que el founder tuvo y validó como **legítimas**, pero que **NO se trabajan hoy** por timing, scope o falta de validación comercial.

Cada idea vive como archivo propio con:

- **Estado** (capturada / en evaluación / retomada / descartada)
- **Origen** (sesión + fecha + quién la propuso)
- **Decisión actual** (por qué no se trabaja ya)
- **Trigger para retomar** (señales concretas que justifican volver a ella)
- **Esbozo técnico** suficiente para arrancar sin re-pensar todo

**Política de cargado:** este folder NO se carga automáticamente al inicio de sesión. Se consulta cuando:

- El founder menciona una idea nueva → revisar si ya está acá antes de tratarla como nueva
- Una nueva señal del mercado / cliente / código sugiere que el trigger de una idea ya se cumplió
- El founder pregunta "qué teníamos pendiente de ideas"

**Política de promoción:** cuando una idea cumple su trigger y se decide trabajarla, se promueve a `memory/spec-<nombre>.md` con plan ejecutable + se mueve este archivo a `memory/ideas-futuras/_implementadas/<nombre>.md` con nota de "implementada en spec-X".

**Política de descarte:** si una idea queda obsoleta (founder cambió de visión, mercado cambió, etc.), se mueve a `memory/ideas-futuras/_descartadas/<nombre>.md` con nota de razón y fecha. Nunca borrar.
